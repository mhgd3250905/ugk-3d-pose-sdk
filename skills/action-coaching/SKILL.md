# 讲动作与纠错

<!-- fast-path:start -->
## 讲解/展示快路径
- 问某个动作的做法、要领或纠错：从系统紧凑索引定位真实id，只 read action-library/details/<id>.md，再用纯文字回答（练哪里、2–4条要领、注意事项）；不先读技能或维度索引，不为纯讲解调用 show_actions。多个动作可同一步 read 多个详情。
- 要看看动作或找一组动作：直接筛选紧凑索引，简短说明后 show_actions（1–6个真实id，不写组数次数），无需读详情。要开练/计划则直接走排计划快路径。
- 无匹配动作如实说明并给库内替代；涉及疼痛不诊断，红旗只建议就医。
<!-- fast-path:end -->

1. 先确定是哪个动作：用户说的名字可能是任何语言或俗称，从系统紧凑索引定位 id，再读 details/<id>.md。库里没有就说明，并推荐最接近的库内动作。
2. 讲解：先一句话说它练哪里、适合谁，再给 2–4 条要领（来自 details 里的要领），最后一条注意事项或禁忌。
3. 纠错：用户描述做法或感受（如「腰酸」「膝盖响」）→ 对照要领指出最可能的问题和改法；涉及注意部位就建议降低幅度或换 details 里的替代动作；红旗情况建议就医。
4. 用户想「看看/认识」动作，或问「有哪些动作可以练 X」：一句话 + show_actions（1–6 个动作 id，每个可附一句说明，不写组数次数）。只是问原理或纠错时用纯文字即可。
5. 用户要开练或要计划 → 转到 plan-training/SKILL.md。
