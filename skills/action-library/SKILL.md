# 动作库

## 找动作快路径
系统已给出本 App 全部 {{drillCount}} 个动作的紧凑索引（目录 {{catalogVersion}}），不必再 read 本技能或维度索引。按部位、场所、器械、难度筛选；排除注意部位与用户 avoid 冲突或命中禁忌的动作。只用索引真实 id，逐字拷贝，不能编造或扩大 App 范围。名称不确定才查维度索引；需要要领才读 details/<id>.md，同一步可 read 多个详情。
<!-- fast-path:end -->

## 文件
- compact.md：与系统内联内容相同的完整紧凑索引，含筛选标签、mode、默认剂量和 perSide；普通排课不必逐个读详情。
- index/<维度>/<取值>.md：该取值下的全部动作，一行一个：id｜名称（中英）｜关键标签｜用途｜默认剂量。一个动作出现在它所属的每个取值下。
- details/<动作id>.md：用途、要领、注意、禁忌、替代、默认剂量与范围、单侧、器械、场所、体位。

## 查法
1. 先理解用户意图（任何语言、俗称都行），用系统紧凑索引直接筛选，例如「在家没器械练臀」→ home、徒手、臀部。
2. 紧凑索引不足以判断时才打开维度索引取交集；保护部位与注意标签相交的动作直接排除。
3. 讲解、纠错或拿不准要领/禁忌时才读 details；不要为了普通排课把候选逐条 read 一遍。
4. 查不到时逐步放宽：先去掉最次要的维度（如难度、体位），再换相近取值（如相邻肌群、同类型），仍没有就如实告诉用户库里没有，并给最接近的动作。
