# AI 问答推荐 Agent v2（原型，可选启用）

状态：原型，分支 `codex/coach-qa-agent-v2`。与现有 `CoachAgent` 并存，没删旧代码，App 都没改。
入口：`package:ugk_coach/ugk_coach_qa_v2.dart` → `CoachQaAgent`。

> 和 `docs/coach-agent-spec.md` 有几处偏离（条件由代码分步收集、不走 source/quote 流程、工具从 14 个减到 4 个）。这是用户已批准的 v2 设计，要不要进主线由用户决定。
>
> 第二轮（下方「第二轮」一节）把第一轮的「完全不问场地」改回了「先确认条件」：按用户的原意，由代码分两步问地点和器械。

## 解决 v1 的五个问题

| v1 问题 | v2 做法 |
|---|---|
| 8 个场景第一轮反问「在哪练」，问法混乱 | 第二轮起：由代码的小状态机分两步问（先地点、再器械），说过的、答过的、记忆里有的都不问，不连问（见「第二轮」） |
| 14 个工具，一次推荐要调 2–7 次模型 | 4 个工具：`respond` / `build_plan` / `find_actions` / `ask_user`。代码先按原话预检索 8 个候选放进用户消息，模型大多一次调用就能作答 |
| search_actions 取标签交集、不排序，整串子串匹配 | `QaFinder`：先硬过滤（场景、器械、躺地、冲击、避开部位、难度上限），再打分排序（主动肌 / 被拉伸肌、目的、sessionRole、难度贴合、名称分词 bigram、点名器械），并去掉同组变体，每个结果带一句代码生成的理由 |
| 备注是套话，知识题和安全题不附动作 | prompt 禁止套话，代码再兜底删掉「全程不憋气…」这类尾巴；每张动作卡一句「为什么适合你」；知识题、安全题按规则附动作 |
| 「第二个 / 太难了 / 这几个」不绑定上次的内容 | `CoachQaState` 记住上次展示的卡片和计划。换第 N 个、换简单点/难一点、就用这几个都由代码按 ai-tags 的 alternatives / regressions / progressions 处理，**不调模型** |

## 组成

- `qa_action.dart`：`QaAction`。有 Pose-Hub `catalog/ai-tags`（`pose-hub-ai-tags@1`）标签就用标签，按 id 对不上的回退到目录字段；`QaActionIndex.taggedCount` 统计覆盖率。
- `qa_lexicon.dart`：中文口语同义词典（瘦肚子→有氧+腹部，翘臀→臀大肌/臀中肌，膝盖疼→避开膝，西裤/不躺→不躺地，楼下/安静→最多低冲击，睡前/跑后/晨起→拉伸目标……），外加场景词、器械词、「只有 X」、时长、跟进句识别。
- `qa_finder.dart`：硬过滤和打分。负重器械不拿环境物替代（哑铃不能用水瓶顶），垫子可以用毛巾顶。候选少于 4 个时只放宽「目的」，不放宽硬过滤。
- `qa_plan_builder.dart`：模型只给主训练 id 和分钟数，代码排 热身(2) / 主训 / 收操(2)（≥9 分钟才排，纯拉伸不加热身），调组数、增删动作，直到 `PlanDuration` 估算落在目标 ±12% 内。产出现有的 `TrainingPlan`。
- `coach_qa_agent.dart`：`CoachQaAgent.send(text, language:)` → `CoachQaReply{kind, text, cards[{id,name,why}], chips, assumption, plan, planSeconds, question, llmCalls, elapsed, usage}`。

## 评测（真实模型，只跑一遍）

`SIM_AGENT=v2 AI_TAGS_DIR=…/catalog/ai-tags/actions dart run tool/sim_user.dart scenarios.json out.jsonl`

- 配置和 v1 一样：SmartFit profile、deepseek-flash（思考开启）、中转 ai.uuugk.win。场景是同样的 20 个，另加 3 个多轮跟进（换第二个、肩痛后排计划、换场地）。
- 打分标准：切题、无多余反问、具体、安全、速度，每项 1–5 分，v1 和 v2 都由同一人按同一标准打。

| | v1 | v2 |
|---|---|---|
| 平均分（5 项均值） | 3.26 | 4.52 |
| 反问场地/时长 | 9 轮（8 个场景） | 0 |
| 平均每轮模型调用 | 3.38 | 0.92（需要调模型的轮 1.05） |
| 每轮耗时 平均 / 中位 / 最大 | 10.4 / 7.9 / 26.5 秒 | 5.7 / 5.5 / 14.4 秒 |
| 推荐 / 计划 | 2–7 次调用 | 都是 1 次，平均 6.7 / 6.1 秒；代码跟进 0 次调用，<0.2 秒 |

v2 最差的三个场景：
1. S09「想练背 → 太难了」：退阶把热身和收操也换了，有两个换成了提踵（不是练背的动作），时长从 15 分钟涨到 20 分钟。评测后已修复：只换主训练；退阶和替换必须和原动作练同一处；换完按原时长重排。修复只经过离线测试，没有重跑真实模型。
2. S17「只有弹力带练手臂」：14.4 秒，2 次调用（模型多查了一次 find_actions）。另外它说库里没有二头动作：确实没有弹力带弯举，但也没提可以换别的器械。
3. S18「随便练练」：一次调用就花了 14.4 秒（模型思考时间长），内容没问题。

评测后又改了一处（同样没重跑）：点名了部位但一处都没练到的动作，排序时重罚。这样肩痛问练胸、办公室练核心时，不会再混进提踵、消防栓这类凑数的动作。

## 第二轮：先确认条件 + 准确性

### 条件收集（代码控制，问句是固定模板）

| 步骤 | 什么时候问 | 选项 |
|---|---|---|
| 1. 地点 | 没说地点、而且地点会明显改变答案：练某个部位、来一套 X 分钟、燃脂、随便练练 | 居家 / 健身房 / 办公室 / 直接推荐（单选） |
| 2. 器械 | 只在「居家」且没说器械时问（酒店算居家） | 哑铃 / 瑜伽垫 / 椅子 / 弹力带 / 都没有（徒手） / 直接推荐（多选） |

- 不问的情况：拉伸放松（跑后、睡前、晨起）、纯知识题（多久、正常吗、怎么办）、伤痛和安全题、周计划、点名某个动作、原话已说「只有弹力带 / 徒手」。
- 问的目的只是**圈定动作范围**，之后严格按范围过滤（`QaQuery.strict`），不越界：
  - 健身房：不限场景、不限器械，全库里找能练目标部位的动作。
  - 居家：只用选中的器械，外加墙（家里总有墙，不用问）；选「都没有」= 徒手 + 墙。椅子、垫子要选了才算。
  - 办公室：只到椅子 + 徒手，不用垫子，不躺地。
- 说过的不问：原话里的地点/器械、本会话答过的、注入记忆（`CoachQaMemory`）里有的，都跳过，改为写一句「按上次：在家哑铃」并给「换场地」chip。
- 同一个问题不连问两次。没回答、回了别的（如「太难的不要」）、或点「直接推荐」，就按在家徒手直接出结果，写「按在家徒手」并给「换场地」；回答里顺带的要求（难度、时长、伤痛）照样用上。
- 条件在会话里记住：之后「再来一套」「换成 20 分钟」「那练背呢」都沿用，不再问。用户点「换场地」会再问一次地点，然后按原请求重出。
- 问题用现有 `AskUserQuestion`（choice 模式，器械 `multiple: true`），经 `AskUserGate.check` 生成；`CoachQaReply.askStep` 标明是 place / equipment。App 把点的选项文字（多选用「、」连接）原样 `send` 回来即可。
- 问句：代码固定模板，不调模型（第三轮改）。地点「练背的话，你在哪练？」，器械「在家练背，手边有哪些器械？可以多选。」，只按原话填部位（没部位就不填）。模型自己调 `ask_user` 问场地/器械会被代码拦下。

### 准确性改动

- 器械不够时如实说：点名的部位在当前范围里一个主练动作都没有时，代码算出「最接近的动作」和「加什么器械就能做什么」，交给模型并在正文兜底补一句（例：只有弹力带练手臂 →「库里没有用弹力带主练二头的动作…加一对哑铃就能做哑铃交替弯举」）。
- 「第 N 个」按卡片上显示的编号（第三轮改，见下）；换上来的动作不会和计划里其他动作重复。
- 「太难了 / 换第 N 个」：新动作必须练到原动作在用户点名部位里练到的那部分（练背时不会换成深蹲）；范围里没有更简单的就如实说，不越界。
- 新增代码跟进：「换成 N 分钟」（同动作重排）、「再来一套」（同条件换一批主训练），都不调模型。
- 硬边界兜底：模型从历史里拿来的越界动作（范围、伤痛、躺地）一律去掉，计划正文补一句已去掉；正文说「不跳」时去掉名字带「跳」的动作、计划按零冲击排；「不能出声/楼下」改为只要零冲击。
- 模型漏给动作卡时，按正文点到的动作名补卡。

### 评测（真实模型，全量只跑一遍）

- 40 个场景、81 轮：原来的 20 个 + 3 个多轮，新增 17 个偏难的（腰突练核心、手腕疼练胸、膝盖术后、只有哑铃/弹力带、宿舍小且不能出声、连续修改 6 轮、含糊问法、英文、条件收集的回答/不答/直接推荐、记忆、换场地 chip、酒店）。场景文件和逐轮期望在评测目录，不提交。
- 每轮跑代码自动检查（`tool/qa_checks.dart`）：部位、场地器械范围、伤痛禁忌、躺地/冲击、文字和卡片矛盾、多余反问和连问、修改类跟进（只换该换的、部位和时长不变）、假设和「换场地」、器械缺口。
- 打分标准和第一轮一样（切题、问得对、具体、安全、速度，各 1–5），同一人打。

| | 第一轮 v2 | 第二轮 |
|---|---|---|
| 平均分（原 20 题） | 4.52 | 4.57 |
| 平均分（40 题） | — | 4.47 |
| 条件问题 | 不问 | 该问地点 17/17、该问器械 12/12、不该问的 52/52 都对，没有连问 |
| 自动检查不过 | — | 7 轮 12 条（81 轮） |

| 每个回答轮模型调用 | 1.05 | 1.17 |

自动检查不过的 7 轮：
- 3 轮「说不跳却有弓步蹲/低冲击开合跳」（S18、S30、S39）：开合跳是真矛盾；弓步蹲是标签把冲击标成了 low（见标签清单）。
- 3 轮「推荐却没给动作卡」（S09 太难了、S23 和 S38 换到办公室）：范围收得很窄时模型只写了文字。
- 1 轮越界（S22 选了徒手，计划里却有要椅子、垫子的俯卧撑）：模型用了上一轮的动作。

评测后修了这几处，并用 5 个针对性场景（S09、S18、S22、S23、S38）重跑真实模型，检查全部通过：越界动作硬去掉、漏卡补卡、「不跳」兜底、范围里没有更简单的就如实说、措辞 6 秒超时。原 20 题里上一轮只离线修过的两处也复测了：S09 退阶不再换到别的部位（计划退阶时长不变由单测覆盖）；肩痛练胸、办公室练核心、跑后拉伸都没再混进不相干部位的动作。

最差的 3 个场景：
1. S22 肩痛 → 排 10 分钟 → 居家 → 徒手：计划用了范围外的动作（已修，复测通过；修后徒手范围里能练胸的只剩 2 个动作）。
2. S38 / S23 换到办公室练胸、练腿：办公室范围很窄（椅子 + 徒手），模型只写文字没给卡（已修为按正文补卡）。练胸只有「扶凳上斜俯卧撑」一个动作。
3. S09 在家徒手练背 → 太难了：严格徒手下库里主练背的只有「坐姿撑地抬臀」一个，「太难了」也找不到更简单的（已改成如实说并建议加垫子或弹力带）。

## 第三轮：三处小改（2026-11-03 用户决定）

1. **徒手默认含墙**：居家（酒店）圈定范围后墙总是可用（`homeAlwaysAvailable`），选「都没有（徒手）」也能做只要墙的动作；椅子、垫子仍要选了才算。办公室不变（椅子 + 徒手）。
2. **问句全部固定**：地点、器械两个问题都用代码模板，不再调模型措辞，问题轮不发网络请求。
3. **「第 N 个」= 卡片上的编号**：计划卡片（`toCoachRoutine` → `CoachRoutine.items`，`plan_expanded` 显示 `i + 1`）把所有块的动作拉平连续编号，含热身和收操，从 1 开始。所以对计划说「换第 N 个」就换卡片第 N 个（可能是热身或收操），其余位置不动；动作卡（推荐）按展示顺序编号。超出范围时回复「一共 X 个动作，要换第几个」；范围里没有可替换的就如实说并保留。给模型的状态和历史里，计划和动作卡也带同样的编号。`CoachQaReply.planOrderedIds` 是卡片顺序。

复测（真实模型 deepseek-flash 思考开启，只跑受影响的 23 个场景、72 轮：所有含提问的场景、徒手练背/练胸/练腹、含「第 N 个」的多轮；新增 S41 徒手练胸、S42 徒手练腹、S43 徒手练背计划换第 1 / 第 4 个）：
- 提问 35 轮：该问/不该问 72/72 都对，0 次模型调用，平均 13 毫秒、最慢 80 毫秒。
- 「换第 N 个」6 轮：编号全部和卡片对上（S43 第 1 个是热身，换成了同环节动作；第 4 个是主训练）。
- 徒手（含墙）主练动作数：练背 1→2（多了「靠墙天使」），练胸 1→1（库里没有只要墙的推胸动作），练腹 3→3。
- 自动检查只有 1 条不过：S20「说不跳却有前跨步弓步蹲」，是已知的标签问题（弓步蹲冲击标成 low），和这次改动无关。
