# 动作库

本 App 共 {{drillCount}} 个动作（目录版本 {{catalogVersion}}）。只能用这里的动作；最终工具里的每个 id 都必须来自你读到的文件，逐字拷贝，不许编造或改写。

## 文件
- index/<维度>/<取值>.md：该取值下的全部动作，一行一个：id｜名称（中英）｜关键标签｜用途｜默认剂量。一个动作出现在它所属的每个取值下。
- details/<动作id>.md：用途、要领、注意、禁忌、替代、默认剂量与范围、单侧、器械、场所、体位。

## 查法
1. 先理解用户意图（任何语言、俗称都行），定出相关维度和取值：例如「在家没器械练臀」→ scene=home、equipment=none、muscle=glute-max。
2. 打开对应索引文件，取交集挑候选（通常 1–3 个索引就够）。用户要保护某部位时，读 caution 下对应文件，把里面的动作排除。
3. 只对最后要用或拿不准的候选读 details（每个动作读一次即可）。
4. 查不到时逐步放宽：先去掉最次要的维度（如难度、体位），再换相近取值（如相邻肌群、同类型），仍没有就如实告诉用户库里没有，并给最接近的动作。
