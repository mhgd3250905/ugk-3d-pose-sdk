## 第四轮：模型照 SOP 理解，代码只管和语言无关的部分

### SOP

- 文件：`lib/src/qa_v2/coach_qa_sop.md`（给模型的说明书，像一个 Skill）。改 SOP 只改这个文件，然后 `dart run tool/gen_qa_sop.dart` 生成 `coach_qa_sop.g.dart`（SDK 是纯 Dart，不读资源文件；单测检查两边一致）。App 也可以用构造参数 `sop:` 换成自己的版本。
- 每次模型调用的系统提示词 = 整份 SOP + 应用名和 profile.focus；用户消息里写明「当前步骤」和结构化的上下文块（已知条件、上一轮问过什么、卡片编号和标签、范围、候选）。
- 内容：判断类型（actions / plan / knowledge / safety / swap / easier / harder / retime / another / use_these / change_place / chat）→ 按顺序收集条件（地点 → 只有居家才问器械；健身房全库；办公室椅子 + 徒手、不躺地；酒店宿舍等按居家但用用户自己的说法）→ 已知的不问、不连问、用户不答就按已知条件或在家徒手 → 换动作 / 退阶 / 「第 N 个」（卡片连续编号含热身收操）→ 各工具要填的字段 → 正文自查和卡片一致。

### 每轮几步、几次模型调用

| 步骤 | 工具 | 调用次数 | 做什么 |
|---|---|---|---|
| 1 理解 | `fill_form` | 1 | 语言、类型、地点（含用户原词）、器械、要练的肌肉/类型/目的/动作模式（全是 id）、限制、时长、卡片编号、是否在回答问题、下一步问还是答 |
| 2A 问 | `ask_user` | 1 | 只在第 1 步要问时：问句和选项由模型用用户语言写（地点单选 4 项、器械多选 6 项、安全追问） |
| 2B 答 | `respond` / `build_plan` / `swap` | 1 | 只在第 1 步要答时：从代码给的范围内候选里选，写正文、理由、假设说明、chips |
| 3 改写 | `rewrite` | 0（只在不一致时 1） | 正文提到卡片外的动作，或有动作因越界被去掉：带最终卡片清单让模型重写 |

所以：问题轮 2 次调用，回答轮 2 次（少数 3–4 次）。每一步的输出不合规（选了候选外的 id、换动作没从该编号的候选里选、要动作却没给卡、问句为空）会把原因回给模型，同一步内重试，最多 3 次。每轮在 `CoachQaReply.steps` 里记每次调用的步骤名和毫秒数。不设耗时上限。

### 代码只做什么（和语言无关）

- **圈定范围**（`QaFinder.passes`，只看结构化标签）：场景、器械 id（居家 = 选的器械 + 墙；办公室 = 椅子 + 徒手、不躺地；健身房不限）、躺地、冲击（quiet → 只要零冲击）、避开关节（负担 moderate 以上排除）、难度（easy → ≤2）、小空间不排走动动作。
- **按标签排序**：主动肌 / 被拉伸肌 / 训练类型 / 目的 / 环节 / 动作模式命中加分，难度超出扣分，同组变体去重。只把范围内的前 12 个连同标签交给模型。
- **换动作候选**（`QaFinder.swapCandidates`）：同一处（主动肌或被拉伸肌有交集）、用户点名部位里原动作练到的那部分也要练到、同环节、在范围内；easier 只列更简单的，harder 只列更难的；标签 regressions / progressions / alternatives 排前面。热身/收操没有同一处的，放宽到同环节且照顾本次主训练部位。模型从中选一个并写理由；某个编号候选为空就如实说没得换。
- **排计划**（`QaPlanBuilder`）：模型只给主训练 id 和分钟数，代码排热身 / 收操、组数，落在目标 ±12%。改时长沿用原来的热身收操（含换过的）。
- **结构化状态**：地点、器械、来源（用户说的 / 刚答的 / 记忆 / 跳过默认）、上一轮问了哪一步。代码只拦两种情况：已知的还要问、同一个问题连问。跳过（只对地点、器械问题）→ 在家徒手。
- **一致性**：卡片动作必须都在范围内；正文里出现卡片外的动作名（按目录里各语言的名字字面匹配）就让模型重写一次。
- **思考档位**：每次请求带 `thinking: {type: enabled}` + `reasoning_effort: max`（`LlmRequest.extraBody`，新加的字段，合并在 `LlmConfig.extraBody` 之后）。中转站 `deepseek-v4.1-flash` 上 `max` 的推理 token 约是默认档的 2–3 倍（同一题 1047 vs 370）。

### 第四轮评测（真实模型 deepseek-v4.1-flash，思考 max，中转 ai.uuugk.win）

只跑受影响的 11 个场景（S04 S09 S14 S20 S21 S22 S29 S30 S32 S39 S43）+ 2 个新场景（S44 日语「背中を鍛えたい」4 轮、S45 西语「quiero entrenar piernas en casa」4 轮），每个 2 次，共 92 轮。跑完修了 2 处（用户「直接推荐」时模型替用户填了器械 → 代码不再采用、记为默认；模型给「练背」加了二头 → SOP 写明只填用户说的部位），再把 S29、S44 各跑 2 次（12 轮）确认。

| | 结果 |
|---|---|
| 该问 / 不该问 | 92/92 对（复测 12/12）：地点、器械、不问都符合；没有连问；「酒店 / 宿舍」问句用了用户的说法；日语、西语问句和选项都是对应语言 |

剩下的问题：
- 范围很窄时计划会比要求的短（S22 在家徒手 + 肩痛练胸，只有 1 个合格推类动作，10 分钟排出 6 分钟）。

- 正文说法和标签是否一致，代码只核对动作名；「不跳 / 不用躺」这类说法靠 SOP 让模型自查。
- 目录没有日语、西语动作名：卡片显示英文名，少数没英文名的显示中文（如「站姿弹力带面拉」）。

### 解决 v1 的五个问题

| v1 问题 | v2 做法 |

| 备注是套话，知识题和安全题不附动作 | prompt 禁止套话，代码再兜底删掉「全程不憋气…」这类尾巴；每张动作卡一句「为什么适合你」；知识题、安全题按规则附动作 |

### 组成（第三轮时，已过时）

- `qa_action.dart`：`QaAction`。有 Pose-Hub `catalog/ai-tags`（`pose-hub-ai-tags@1`）标签就用标签，按 id 对不上的回退到目录字段；`QaActionIndex.taggedCount` 统计覆盖率。
- `qa_lexicon.dart`：中文口语同义词典（瘦肚子→有氧+腹部，翘臀→臀大肌/臀中肌，膝盖疼→避开膝，西裤/不躺→不躺地，楼下/安静→最多低冲击，睡前/跑后/晨起→拉伸目标……），外加场景词、器械词、「只有 X」、时长、跟进句识别。
- `qa_finder.dart`：硬过滤和打分。负重器械不拿环境物替代（哑铃不能用水瓶顶），垫子可以用毛巾顶。候选少于 4 个时只放宽「目的」，不放宽硬过滤。

- `coach_qa_agent.dart`：`CoachQaAgent.send(text, language:)` → `CoachQaReply{kind, text, cards[{id,name,why}], chips, assumption, plan, planSeconds, question, llmCalls, elapsed, usage}`。

### 第二轮：先确认条件 + 准确性

### 条件收集（代码控制，问句是固定模板）

| 步骤 | 什么时候问 | 选项 |
|---|---|---|
| 1. 地点 | 没说地点、而且地点会明显改变答案：练某个部位、来一套 X 分钟、燃脂、随便练练 | 居家 / 健身房 / 办公室 / 直接推荐（单选） |
| 2. 器械 | 只在「居家」且没说器械时问（酒店算居家） | 哑铃 / 瑜伽垫 / 椅子 / 弹力带 / 都没有（徒手） / 直接推荐（多选） |

- 不问的情况：拉伸放松（跑后、睡前、晨起）、纯知识题（多久、正常吗、怎么办）、伤痛和安全题、周计划、点名某个动作、原话已说「只有弹力带 / 徒手」。
- 问的目的只是**圈定动作范围**，之后严格按范围过滤（`QaQuery.strict`），不越界：
  - 健身房：不限场景、不限器械，全库里找能练目标部位的动作。
  - 居家：只用选中的器械，外加墙（家里总有墙，不用问）；选「都没有」= 徒手 + 墙。椅子、垫子要选了才算。
  - 办公室：只到椅子 + 徒手，不用垫子，不躺地。
- 说过的不问：原话里的地点/器械、本会话答过的、注入记忆（`CoachQaMemory`）里有的，都跳过，改为写一句「按上次：在家哑铃」并给「换场地」chip。
- 同一个问题不连问两次。没回答、回了别的（如「太难的不要」）、或点「直接推荐」，就按在家徒手直接出结果，写「按在家徒手」并给「换场地」；回答里顺带的要求（难度、时长、伤痛）照样用上。
- 条件在会话里记住：之后「再来一套」「换成 20 分钟」「那练背呢」都沿用，不再问。用户点「换场地」会再问一次地点，然后按原请求重出。
- 问题用现有 `AskUserQuestion`（choice 模式，器械 `multiple: true`），经 `AskUserGate.check` 生成；`CoachQaReply.askStep` 标明是 place / equipment。App 把点的选项文字（多选用「、」连接）原样 `send` 回来即可。
- 问句：代码固定模板，不调模型（第三轮改）。地点「练背的话，你在哪练？」，器械「在家练背，手边有哪些器械？可以多选。」，只按原话填部位（没部位就不填）。模型自己调 `ask_user` 问场地/器械会被代码拦下。

### 准确性改动

- 器械不够时如实说：点名的部位在当前范围里一个主练动作都没有时，代码算出「最接近的动作」和「加什么器械就能做什么」，交给模型并在正文兜底补一句（例：只有弹力带练手臂 →「库里没有用弹力带主练二头的动作…加一对哑铃就能做哑铃交替弯举」）。
- 「第 N 个」按卡片上显示的编号（第三轮改，见下）；换上来的动作不会和计划里其他动作重复。
- 「太难了 / 换第 N 个」：新动作必须练到原动作在用户点名部位里练到的那部分（练背时不会换成深蹲）；范围里没有更简单的就如实说，不越界。
- 新增代码跟进：「换成 N 分钟」（同动作重排）、「再来一套」（同条件换一批主训练），都不调模型。
- 硬边界兜底：模型从历史里拿来的越界动作（范围、伤痛、躺地）一律去掉，计划正文补一句已去掉；正文说「不跳」时去掉名字带「跳」的动作、计划按零冲击排；「不能出声/楼下」改为只要零冲击。
- 模型漏给动作卡时，按正文点到的动作名补卡。

### 第三轮：三处小改（2026-11-03 用户决定）

1. **徒手默认含墙**：居家（酒店）圈定范围后墙总是可用（`homeAlwaysAvailable`），选「都没有（徒手）」也能做只要墙的动作；椅子、垫子仍要选了才算。办公室不变（椅子 + 徒手）。
2. **问句全部固定**：地点、器械两个问题都用代码模板，不再调模型措辞，问题轮不发网络请求。
3. **「第 N 个」= 卡片上的编号**：计划卡片（`toCoachRoutine` → `CoachRoutine.items`，`plan_expanded` 显示 `i + 1`）把所有块的动作拉平连续编号，含热身和收操，从 1 开始。所以对计划说「换第 N 个」就换卡片第 N 个（可能是热身或收操），其余位置不动；动作卡（推荐）按展示顺序编号。超出范围时回复「一共 X 个动作，要换第几个」；范围里没有可替换的就如实说并保留。给模型的状态和历史里，计划和动作卡也带同样的编号。`CoachQaReply.planOrderedIds` 是卡片顺序。
